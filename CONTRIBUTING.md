# Contributing to CoverGrail

CoverGrail is a Next.js/TypeScript comic pre-grading workspace backed by Supabase Auth, Postgres, Storage, RLS, and Edge Functions.

Before a pull request, run the repository's regression, build, dependency-audit, Playwright, accessibility, and security checks that apply to your change.

Preserve the distinction between educational pre-grading support and official professional grading. Keep user collection data and comic images private by default.

A merged commit is not automatic approval for a production deployment.
