# CoverGrail Roadmap

This roadmap describes direction, not guaranteed dates.

## Shipped

- structured comic image intake
- private authenticated collection
- Supabase Auth/Postgres/Storage/RLS production path
- duplicate grading and quota protections
- image-signature validation
- staged AI adapter architecture
- regression, accessibility, security, and browser QA

## Improving

- production grading-flow clarity
- upload/error recovery
- model-independent defect explanations
- collection comparison workflows

## Exploring

- live vision grading providers
- richer confirmed-grade comparison analytics
- export/share tools that preserve private defaults

## Product boundary

CoverGrail is educational pre-grading decision support, not an official CGC/CBCS grade. Reliability and privacy should stay ahead of model novelty.
